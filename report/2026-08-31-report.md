## 2. 重要决定

1. **`/stats` 整页删除而非隐藏**：侧边栏入口彻底删除，路由文件一并删除；月/年视图在 `/calendar` 统一渲染。理由：年视图逻辑与日历「按年聚合」语义相同，与月视图共享 `allEntries` / `booksById`，避免数据双源。
2. **月份导航标题随 view 切换粒度**：月视图显示 `2026-08`，年视图显示 `2026`；`<`/`>` 切月 / 切年 — `shift(delta)` 通过 `view` 分发。
3. **统计页 title 写死「统  计」**（带 letterSpacing 4）：即使原 `/calendar` label 是「日历」，合并后统一叫「统计」，与侧边栏入口对齐。
4. **设置页菜单项用 SF Symbol 而非 emoji**：iOS 上 SymbolView 渲染系统级单线图标（`snowflake` / `square.and.arrow.up`），与整 App 图标语言一致（book detail 用 `⋯` 是历史遗留例外）。
5. **设置页 `...` 占位不绑动作**：右上的 `⋯` 目前 no-op，避免在没设计稿时编造菜单；待有具体动作再加。
6. **`__DEV__` 诊断入口移到 `/settings/export`**：主设置页保持 Figma 设计完全一致（仅 2 行），诊断藏在导出页底部，仅 dev 可见。

## 3. 遇到的问题与解决方法

| # | 问题 | 解决 |
|---|---|---|
| 1 | **Figma MCP / WebFetch 在本会话不可用**（memory `figma-mcp-blocked-in-non-interactive-sessions`） | 严格基于参考图实现，月/年 toggle 与年视图所有布局（4 卡 / 进度条 / 12 柱图 + 旋转 label）按参考图复刻；细节偏差以用户下一轮反馈为修正信号 |
| 2 | **`SymbolView.name` 类型为 `SFSymbol`（SF Symbols 7.0 全量联合），不接受 `string`** | `SF_SYMBOLS` / `MenuItem.symbol` 改为 `SFSymbol` 类型，从 `sf-symbols-typescript` import；这样 TS 在编译期就能校验图标名字拼写 |
| 3 | **`StyleSheet.absoluteFillObject` 在新 RN 类型中已移除**（Drawer.tsx 旧报错） | 展开为 `{position:'absolute', top:0, left:0, right:0, bottom:0}`，无外部行为差异 |
| 4 | **`pathname === '/settings/ai'` 时 drawer header 没让位**（初次实现漏判） | `showHeader` 改 `!pathname.startsWith('/settings')`，覆盖所有子路径 |
| 5 | **Expo Router 同时存在 `settings.tsx` 和 `settings/` 目录会冲突吗** | 实测不会：`settings.tsx` 渲染 `/settings`，`settings/ai.tsx` 渲染 `/settings/ai`，expo-router 把 `settings/` 当目录但不强制要求 `_layout.tsx` |
