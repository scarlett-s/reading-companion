# 开发报告 — 2026-08-18

> 读书记录 App（Reading Companion）Phase 1 记录核心，本轮完成情况与下一步计划。

## 1. 今天完成的任务

### 1.1 项目骨架
- 用 `create-expo-app` 搭建 **Expo SDK 57** 项目（React Native 0.86、React 19、TypeScript，严格模式）。
- 配置 expo-router 文件路由（`src/app/`）、`@/*` 路径别名、typedRoutes + reactCompiler 实验开关。
- 引入 **expo-sqlite（SDK 57 新异步 API）** 作为本地存储。

### 1.2 数据层（本地 SQLite）
- `src/db.ts`：建表 + 全套 CRUD。
  - 图书（Book）、每日记录（ReadingEntry）、整理（Reflection）、设置（Settings）四张表。
  - `getRecentBooks(limit)` 按「最近记录时间」排序取书架。
  - 记录可含页数 / 百分比（至少一项）、评论可空。
- `src/utils.ts`：纯函数（日期、进度归一化、关键点解析）。

### 1.3 AI 通路
- `src/ai.ts`：`fetch` 直调 **OpenAI 兼容接口**，不引重型 SDK。
  - 主用 DeepSeek（`deepseek-chat`），同通路兼容 Ollama（离线）。
  - 三个能力：追问（generateQuestion）、提炼要点（extractKeyPoints）、整理（synthesizeBook）。
- **手动触发**，绝不自动调用；Key 走 `.env`，不写死。

### 1.4 页面（记录核心）
- **首页 = 记录表单**：书名（书库自动补全下拉 + 「＋添加新图书」）、日期（默认今天）、阅读进度（页数/百分比）、评论。
  - 两个按钮：**直接保存** / **Discuss**。
- **Discuss 对话页**：AI 基于评论追问，最多 3 轮，结束提炼要点，一起保存「评论 + 对话 + 要点」。
- **图书详情页**：状态切换（标记读完）+「✨ 整理我对这本书的思考」+ 整理结果 + 历史记录。
- **日历视图**：月历，有记录的天打点，点某天看当天记录。
- **设置页**：AI 配置（baseUrl / apiKey / model），带 DeepSeek / Ollama 预设。
- **添加图书页**：Open Library 搜索（带封面）+ 手动录入兜底。

## 2. 遇到的问题与解决方法

| # | 问题 | 现象 | 解决 |
|---|---|---|---|
| 1 | **Expo SDK 57 API 大改** | 旧写法报错（router / sqlite / Tabs） | 逐个查 v57 版本化文档：`Stack` 从 `expo-router/stack`、`Tabs` 从 `expo-router/js-tabs`、sqlite 用 `openDatabaseAsync`/`runAsync`/`getAllAsync` |
| 2 | **expo-sqlite Web 打包失败** | `Unable to resolve ./wa-sqlite/wa-sqlite.wasm` | `metro.config.js` 加 `assetExts.push('wasm')` |
| 3 | **SharedArrayBuffer 不可用** | 开发服务器无 COOP/COEP 头，SQLite Web 报错 | 自写 `scripts/serve-web.js` 静态服务器显式加 `Cross-Origin-Opener-Policy` / `Cross-Origin-Embedder-Policy` 头 |
| 4 | **Jest 全局名报错** | `tsc` TS2593 `Cannot find name 'describe'` | 测试文件显式 `import { describe, it, expect } from '@jest/globals'` |
| 5 | **依赖装错位置** | jest / jest-expo 进了 dependencies | 重写 package.json 移到 devDependencies |
| 6 | **create-expo-app 报错** | 首次「Permission denied」后中断 | 改用临时子目录 `npx create-expo-app _scaffold --no-install`，再 `rsync` 回根目录（根目录已有 .git 非空） |
| 7 | **浏览器自动化点不动** | 只能识别文本框 uid，点不了按钮 | 改为手动验收：用户确认「添加图书、记录、对话都跑通了」 |
