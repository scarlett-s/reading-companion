## 2. 重要决定

1. **双链采用「关联式」**：显式 `links` 表 + 从「…」菜单打开选择器选笔记，两条笔记双向可见；不用 Obsidian 式 `[[wikilink]]` 文本解析（对非技术用户更直观）。
2. **菜单不加「复制」**：避免引入 `@react-native-clipboard/clipboard` 依赖。
3. **AI 对话键盘放弃第三方库**：最初计划 `react-native-keyboard-controller`，但它是 native module，Expo Go 打不开 → 改用内置 `KeyboardAvoidingView` + `Keyboard` listener。
4. **编辑弹窗删「AI 对话记录」**：AI 交互全部由卡片 AI 图标承载（绿色=发起、灰色=查看已完成），避免重复入口。
5. **豆瓣详情失败时部分字段也填**：能抓到多少填多少，缺的留空，不要求重试。
6. **删除独立笔记详情页**：编辑/删除/关联全部收进「…」菜单，首页卡片即信息载体。

## 3. 遇到的问题与解决方法

| # | 问题 | 解决 |
|---|---|---|
| 1 | **`react-native-keyboard-controller` 导致 App 打不开** | 它是 native module，Expo Go 未内置，`_layout.tsx` 顶层 import 直接挂 → 卸载，改用内置 `KeyboardAvoidingView` + `Keyboard.addListener` |
| 2 | **Fabric（New Architecture）下 `findNodeHandle`/`UIManager.measure` 失效** | SDK 57 默认开启 New Architecture，旧测量 API 返回 null / 不回调 → 先换 `ref.measureInWindow`，最终**改用 `onLayout` + `onScroll` 纯计算**（完全不依赖原生测量） |
| 3 | **豆瓣图床防盗链** | `img*.doubanio.com` 无 Referer 返回 **418** → `expo-image` 的 `source` 加 `headers: { Referer: 'https://book.douban.com/' }` |
| 4 | **豆瓣 `subject_suggest` 不返回出版社/译者/页数** | 详情页 `https://book.douban.com/subject/<id>/` HTML 正则解析补全（`#info` 块扫描作者/译者/出版社/出版年/页数） |
| 5 | **AI 标记状态错乱（mode='chat' 但无对话）** | 之前 `entryHasAI` 只要 `mode==='chat'` 就 true，导致「未真聊」的笔记也标绿 → 改为只看 `discussion.length > 0` |
| 6 | **浮动「收起」按钮多轮不出现** | 测量方案在 Fabric 下失效 → 最终纯 `onLayout`（卡片 y/height）+ `onScroll`（contentOffset）+ `onLayout`（视口高）计算卡片底部是否滚出视口 |
| 7 | **AI 对话弹窗无法滚动** | 嵌套 `Pressable` 吞掉 ScrollView 手势 → 拆开外层 Pressable，暗背景用 `absoluteFill`，卡片用普通 `View`，加 `scrollEnabled`/`nestedScrollEnabled` |
