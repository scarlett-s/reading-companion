## 2. 重要决定

1. **标签最终方案 = 正文 `#` 识别（派生，不落库）**：回退了初版的 `ReadingEntry.tags` 字段 + 独立标签框。标签由 `parseTags`/`segmentTags` 从 `comment` 实时派生，不存 DB（避免派生数据陈旧）。
2. **卡片内联编辑只改正文**：进度、书名、标签都不可在卡片内编辑（只读展示）；标签只能在「新增笔记」时通过正文 `#` 打入。
3. **编辑正文用「高亮层 Text + 透明文字 TextInput」叠加**：RN `TextInput` 不支持富文本，用叠加层实现「编辑时 `#标签` 实时内联高亮」；同时解决长文滚动（见 §3 问题 1/2）。
4. **内联标签去掉水平 padding**：为让叠加层里高亮 Text 与透明 TextInput 逐字对齐，tag 样式只留 `backgroundColor + borderRadius + color`，不设水平内边距。

## 3. 遇到的问题与解决方法

| # | 问题 | 解决 |
|---|---|---|
| 1 | **编辑长文下半被键盘遮挡、无法滚动** | 首页外层包 `KeyboardAvoidingView`（iOS `behavior="padding"`），视口收窄到键盘之上 |
| 2 | **长文编辑滚动范围被光标位置限制**（光标在上只能看到上部，在下才能滚到底） | 根因：多行 `TextInput` 默认内部滚动且高度被 `minHeight` 锁住。改 `scrollEnabled={false}` + 容器随高亮层高度自动增长，让外层 `ScrollView` 接管滚动 |
| 3 | **退出编辑要点两次**（第一次收键盘、第二次才退出） | `ScrollView` 默认 `keyboardShouldPersistTaps="never"`，首击被收键盘吞掉 → 加 `handled` + `Keyboard.dismiss()` |
| 4 | **编辑态无法显示标签样式**（TextInput 纯文本） | 用「透明文字 TextInput 叠在高亮 Text 上」，光标用 `selectionColor`/`cursorColor` 可见 |
| 5 | **`UI ` 目录（带尾随空格）无法正常 ignore** | `.gitignore` 用 `UI[ ]` 匹配（`git check-ignore` 验证生效），普通 `UI/` 或引号写法都不行 |

## 4. 技术变化

- **纯函数**：`utils.ts` 新增 `parseTags(text)`（返回去 `#` 标签名、去重）、`segmentTags(text)`（返回 `{text, tag}[]` 切段，供内联高亮）、`formatProgress(e)`（进度文案，收敛重复实现）。
- **组件**：`NoteCard` 重写为「展示态 + 编辑态」双分支，编辑态用叠加层；`NoteMenu` 加 `onEdit` 回调 + 关联笔记搜索框 + 条目直接切换。

- **原生工程**：`ios/`（expo prebuild 生成）纳入版本管理。
- **测试**：`utils.test.ts` 新增 `formatProgress`(4)、`parseTags`(5)、`segmentTags`(3) 共 12 个用例。
